Secure Columns

Excel add-in that encrypts selected columns before you share a workbook. Recipients do not install anything.

Download manifest.xml Source on GitHub

Install on Windows or Mac Excel

  1. Download manifest.xml above.
  2. Open Excel, then go to Insert → Add-ins → My Add-ins → Upload My Add-in.
  3. Choose the downloaded XML file. Secure Columns appears on the Home tab.

On some Mac builds the menu is Insert → Get Add-ins → Upload My Add-in. The computer must be online so Excel can load the hosted task pane.

Install in Excel on the web

  1. Open the workbook in Excel on the web.
  2. Choose Insert → Add-ins → Upload My Add-in and select the same manifest.xml.

Mac folder sideload (optional)

Copy manifest.xml into Excel’s WEF folder, then restart Excel:

~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/

Hosted files

Office loads these HTTPS URLs from any Mac or Windows machine:

https://ahmadtech2.github.io/Encryptaddin/taskpane.html https://ahmadtech2.github.io/Encryptaddin/manifest.xml
